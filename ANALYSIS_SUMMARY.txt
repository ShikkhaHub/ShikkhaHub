KEY RISKS & MITIGATION
================================================================================
Risk: Database accuracy - If institutions are wrong, platform fails
Mitigation: Weekly spot-checks (5% of data), automated freshness alerts,
            community reporting system

Risk: Vercel API rate limits during peak traffic
Mitigation: Caching strategy, database query optimization, async processing

Risk: Elasticsearch downtime impacts search
Mitigation: Automatic fallback to PostgreSQL full-text search (implemented)

Risk: Cold starts on serverless slow down first request
Mitigation: Optimize bundle sizes, keep dependencies lean, use Vercel Edge

Risk: OpenAI API costs escalate
Mitigation: Token-based pricing limits, response caching, fallback to rules-based

Risk: Data privacy/compliance issues
Mitigation: GDPR compliance, Bangladesh Data Protection Act compliance,
            user consent management, data retention policies
